## ✨ 能做什么

### 📚 找资料

- **课程导航**：按学院 / 课程树逐层浏览，通识课与专业课分板块，同名课程按学院拆分展示
- **搜索**：课程名、课程代码、资料标题与描述全文搜索
- **首页动态**：「为你推荐」「热门资料」「最近上传」「下载最多」，常用校园系统入口直达

### 📖 用资料

- **在线预览**：PDF、图片在浏览器内直接看，不用下载
- **下载**：普通用户每日 15 次下载额度，支持批量打包下载
- **文件详情**：资料类型标记、置顶徽章，可按类型筛选与排序

### 📤 分享资料

- **上传**：在课程页直接上传 PDF / Word / PPT / 图片 / 压缩包等，照片自动清理位置信息
- **人工审核**：上传后由对应板块的版主审核，结果通过站内通知告知
- **新课申请**：找不到这门课？可以直接申请在课程树上创建
- **贡献排行**：上传 / 下载排行榜，还有可展示的公开个人主页

### 💬 问答区

- 提问与回答，两级标签体系，支持点赞、收藏
- 精选与置顶，高频疑问一眼可见

### 🗓️ 课表

- 导入教务系统导出的课表（Excel 格式），支持多学期
- 个人主页展示只读课表

### 👤 个人中心与通知

- 昵称、签名、头像、联系方式、密码自助管理
- 课程收藏与资料收藏
- 站内通知：审核结果、平台公告，点击可直达对应课程

### 📱 移动端

- 响应式设计，手机浏览器直接使用（抽屉式导航）
